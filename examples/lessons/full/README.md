## Python循环累加

python-loop.txt：问题→初始化→逐轮取值/累加→输出→错误版本与边界→总结。

正确演示代码（准备列表后累加部分四行；含列表准备共五行）：

```python
nums = [2, 3]
total = 0
for n in nums:
    total += n
print(total)
```

人工核查状态：

| 动作 | 高亮行 | n | total | 输出 |
|---|---:|---:|---:|---|
| 初始化 | 2 | 尚未绑定 | 0 | 无 |
| 取出二 | 3 | 2 | 0 | 无 |
| 累加二 | 4 | 2 | 2 | 无 |
| 取出三 | 3 | 3 | 2 | 无 |
| 累加三 | 4 | 3 | 5 | 无 |
| 打印 | 5 | 3 | 5 | 5 |

- 正确代码打印在循环外：只有5，不是2、5两个输出。
- 初始化放循环内是单独的错误版本，最后输出3；不能改写正确版本的状态。
- 空列表不执行循环体，最后输出0；未定义n不能伪造为0。
- 列表长度2不等于元素总和5。保留输入为普通整数列表的前提，不声称所有数据类型兼容。
- 取值与累加分开绑定各自动作cue；状态不得在对应讲解前先更新。

# 来源与许可证

`packages/content-skills/` 里的 skill 有两种：

- **自有**：本项目自己写的方法（目前全部 13 个都是，迁移自原先写在代码里的提示词）。
- **改编**：从开源 skill 改编而来。改编时必须在该 skill 的 `SKILL.md` 头部写 `adapted_from: <仓库>@<提交号> (<许可证>)`，并在下表登记；只改编 MIT / Apache 等允许修改再发布的许可证，保留下方的许可证全文。无许可证或「保留所有权利」的仓库只能参考思路，不复制内容。

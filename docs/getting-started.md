## 聚焦处理链（可选，不重新配音）

打开课程→课程设置→视觉风格→**机制演示·聚焦**→保存风格（不重新配音）。仅处理链段启用这轮优化：字幕出现完整句时不在阶段再复印整句，已有源文高亮可作短重点；一个稳定案例标记沿显式相邻连接推进，下一口播事件前收住，读结论时不再整体移动。其他图形仍沿用机制演示。分镜/配音不改、历史冻结不变；新冻结保留聚焦快照。

没有高亮时不自动猜关键词；没有连接不模拟对象移动，分支不会自动推断分流；过长案例引入用中性“示意对象”而不缩成不可读小字。未提供真实参数或结果时不补造。本轮实际工作台隔离验收及同音轨对照通过，未新增模型/TTS费用；主观优劣请看[14.7秒新版](../output/workbench/process-focus/v2/after.mp4)/[前后对照](../output/workbench/process-focus/v2/comparison.jpg)。

## 环境

- **Node.js**：22+、npm。
- **Python（云端生成/工作台/完整测试需要，本地DSL渲染不需要）**：3.10+；`jsonschema` 用于协议校验，`httpx` 调用 HTTP 供应商，`websockets` 接入 TTS 2.0 原生字幕，`python-dotenv` 读取本地配置。
- **系统工具**：PATH 中必须有 `ffmpeg`、`ffprobe`。
- **语音生成**：示例语音生成使用 macOS `say` 与已安装中文语音；其他平台可自备音频和符合协议的 DSL，渲染本身不依赖 macOS。
- **浏览器环境**：第一次导出会下载 Remotion 固定版本的 Chrome Headless Shell，需要网络和额外磁盘空间。之后渲染不需要在线字体或外部媒体。

`/courses`搜索本人课程、查看状态和更新时间、继续编辑；列表卡片可删除整课（不可恢复，有排队/运行中任务时需先进课取消）。`/courses/new`填写标题（及可选受众/时长/要点），可同步生成讲稿或手写讲稿，核对后再免费确认创建草稿；生成接口不创建项目/任务。可选讲解风格「科普 / 知识干货」（缺省科普），写入课程后影响讲稿与后续分镜偏好，改风格不自动重跑已有场景。分镜按讲稿教学动作在现有模板间切换（有材料才换型），不新增组件；预览翻章按模板剪影区分（非同一套四宫格）。课程设置可选视觉风格「纸质幻灯」（建议配浅色教学/彩色信息图主题）；分镜可带 `motif` 专用构图。多样性为提示偏好、不因类型过少单独失败。详见[纸质幻灯设计](superpowers/specs/2026-10-20-paper-slide-richness-design.md)。创建后到`/courses/[id]`手工添加场景，或确认费用后生成分镜；视觉风格/音色/讲解风格复用原编辑器设置与默认值，不复制一套新表单。左侧场景、中间预览、右侧编辑；高级执行器状态默认折叠。已保存的待配音/待对齐章现在可免费播放静音画面草稿，使用明确标注的临时时序，无音轨/字幕、不写回正式分镜；未保存输入不进入预览。已就绪章沿用真实配音预览，整课冻结导出仍需全部就绪。

**怎么启动网页：**见仓库根 [README 快速开始 · 路径 B](../README.md#路径-b打开教学工作台登录--我的课程--新建讲稿)。改 API 代码后若出现 `/api/...` 404，先重载 `8000` 上的 uvicorn，不要只刷新浏览器。

本机草稿按用户隔离、明文存储，不等于服务器保存；不自动迁移旧匿名草稿，共用电脑不要长期保留敏感文稿。离开/退出先确认未保存内容。会话过期锁定原编辑器并要求同账号原位登录，输入保留、不会重发上次写请求；账号读取暂时失败也不卸载已有编辑器。真正切账号或退出清空页面内存。

旧课程不会自动归首个账号。由本机维护者明确选择**已有账号**及课程ID，在备份后逐门认领（原子事务，拒绝抢走其他账号课程）：

```bash
python3 -m services.accounts claim --username <已有账号> --project <明确课程UUID> --confirm
# 忘记密码：本机交互输入新密码，不写入命令参数/聊天/日志，撤销全部旧会话
python3 -m services.accounts reset-password --username <已有账号> --confirm
```

维护命令只用于已初始化账号schema的目标数据库；不能在未备份的原库上试跑。419 Node＋348真实临时数据库环境Python测试、类型检查/私有副本生产构建通过；浏览器注册、新建、编辑/草稿恢复、过期续登及改密通过。双账号完整UI/退出/前进后退链尚待补验，见[证据](../output/workbench/account-course-flow/receipt.json)。

## 候选稿确认与差异

选择章节后展开候选，可查看“已保存 rN → 候选”：列出变化的教学字段，展开查看口播、代码、连线原值，以及当前/候选步骤内容和触发范围。不是逐字高亮；步骤角色、变量等其余信息仍需核对完整只读JSON。摘要不含未保存输入、配音、字幕或时轴，不会自动生成或接受内容。

过期候选显示当前revision，已接受候选仅供查看；忙碌、未保存、章节不符或无法比较的坏数据均禁用接受。确认按钮保留原提示和后端归属/revision校验，取消不提交。候选读取失败、超时或响应格式不符时隐藏旧列表，点击“刷新候选列表”可就地重试，无需刷新整页；5秒超时，读取中禁用重复点击。空列表会明确显示“暂无候选”，不是读取失败。只发GET，不自动重生成或接受，刷新不清未保存输入；切章取消旧请求，晚响应不串到新章。“重新载入”在章节和任务状态未变时也会重新读取。

## 后台任务刷新与超时

后台查询改为一轮完成后等2秒再刷新，不让慢响应与下一轮重叠覆盖新状态。单轮任务/项目读取共用5秒期限；切项目、忙碌切换或卸载时中止旧查询。查询失败/超时会提示列表可能不是最新，恢复后清除本查询警告，但不会清掉其他操作错误。编辑中继续查任务，不回填覆盖未保存稿。

**查询超时不等于取消任务或限制计费**，只中止前端读取；后台任务按原规则继续，需要取消仍须显式操作。新增4项请求兼容/中止回归，354项Node、typecheck及私有构建通过；2项原生只读＋6项受控GET检查分列。原浏览器复现慢查询并发2路及旧状态覆盖，修复后同一脚本峰值1；原数据与localStorage未改，见[验收](../output/workbench/task-poll-qa/receipt.json)。

## 任务响应异常保护

任务查询、批量提交和取消响应校验后才更新界面：坏数据、跨项目、重复任务或不安全任务ID不替换上次有效列表，未保存输入保留；取消响应还需匹配原任务，不能误报其他任务已取消。

**响应异常不代表提交撤销**。不要重复付费提交，先重新读取任务核实；现有查询节奏、取消确认和计费规则不变。

## 显式重试后的状态

确认重试后，工作台直接校验并应用服务器返回的任务状态，不再等下一轮查询；即使查询暂时失败，也能看到已接受的排队状态，“失败”筛选会即时移除该行。服务器返回的旧失败详情仍保留，排队不代表已开始执行或成功。

取消确认不提交；请求失败、任务/项目身份不匹配或坏响应保留原行并提示，不自动补发。读取失败不能证明重试未被接受，应先核对任务状态，勿重复收费提交。既有估价、人工核对、dirty限制和后端重试规则不变。

## 整课导出提交反馈

“冻结版本并导出”先复用完整冻结版本校验（安全ID、项目/revision、DSL及冻结风格），通过后才提交整课渲染。返回任务校验归属、版本和整课范围后立即显示，同ID更新、不重复插行，不依赖下一轮成功查询。坏响应或冲突保留原任务列表，不自动重发。

冻结与渲染是两次操作：冻结成功但渲染失败时，版本可能已存在，先查看版本历史/持久任务，不把读取失败当作全部回滚；任务排队也不是导出完成。原有dirty/导出前检查和后端幂等未改。

## 取消任务与确认停止

任务排队时取消可直接结束；运行中取消只是请求执行器停止。提交成功后列表立即采用服务端返回状态，显示“等待取消确认”并禁用重复点击；仍标为处理中，直到执行器确认终态。失败会提示并保留原状态，重试须手动点击，不自动补发取消。

**已提交取消不代表已停止或免费**：已发出的模型/配音调用可能仍计费，页面不会把运行中的取消请求冒充已取消。

新增4项回归，全量342项Node、typecheck与私有构建通过；2项原生只读检查和6项受控检查分列。受控取消的3次POST全部拦截返回模拟响应，未取消真实任务、派任务或调用供应商；原项目、任务和本机草稿不变，见[验收](../output/workbench/task-cancel-qa/receipt.json)。

```bash
# 生成 5 场景中文配音、DSL 与 Studio props。
npm run demo:create

# 启动后访问终端打印的 localhost 地址；Ctrl+C 退出。
npm run studio

# 导出；目标文件必须不存在。
npm run render -- examples/demo.json output/demo.mp4
```

### 生成文件说明
- `examples/demo.json`：最终可渲染 DSL。
- `examples/demo-props.json`：Studio 的 `{project: DSL}` 输入。
- `apps/renderer/public/demo/*.wav`：真实本地中文语音。
- `output/demo.mp4`、`output/demo.srt`：视频和外置字幕。

### DEMO_VOICE 设置
示例生成默认语音为 `Eddy (中文（中国大陆）)`。若系统未安装，可运行 `say -v '?'` 查看可用语音，然后通过环境变量指定：

```bash
DEMO_VOICE='已安装的中文语音名' npm run demo:create
```

### 注意事项与对齐说明
- 示例音频逐短语合成后拼接，因此短语区间来自真实文件时长，**不是自动强制对齐，也不是词级时间戳**。
- 元素在对应短语开始时入场，不保证与短语内部关键词的偏差小于 0.5 秒。正式对齐与供应商接入属于第二阶段。
- 重新生成示例会更新示例输入和配音，不改已有导出。再次导出使用新文件名，例如 `output/demo-2.mp4`。示例生成文件、依赖和输出不纳入版本管理。

## DeepSeek + 火山生成文案视频

### 1. 配置凭据 (.env)
先复制 `.env.example` 为本地 `.env`，只在本机填写：
- `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`（账户实际可用模型）。
- 火山新版控制台填写 `VOLCENGINE_API_KEY`；旧版填写 `VOLCENGINE_APP_ID` + `VOLCENGINE_ACCESS_KEY`，两种鉴权不能混用。
- `VOLCENGINE_RESOURCE_ID` 与 `VOLCENGINE_SPEAKER`：已开通的资源与中文音色 **ID**，不是音色显示名。

### 2. 执行生成与导出

```bash
# 不覆盖已有本地配置。
cp -n .env.example .env
# 使用编辑器在本机填好 .env；不要把密钥发到聊天里。
# 调用真实供应商，会产生 LLM/TTS 费用。
npm run generate -- examples/script.txt output/cloud-project.json
# 生成成功后复用原导出器。
npm run render -- output/cloud-project.json output/cloud-video.mp4
```

### 3. 生成文件位置与资源保留
生成的音频放在 `apps/renderer/public/generated/<运行ID>/`，包括原始音频、24kHz 单声道 WAV 和供应商 words JSON。目录默认不纳入版本管理，不要删除仍被 DSL 引用的文件。失败时不发布最终 DSL，错误返回 stage、scene_id 和已生成资源目录。已有目标文件会在调用付费接口前被拒绝。

### 4. 输入限制与内容约束
输入最多 4,000 个 Unicode 码点、20 场景、5 分钟；DeepSeek 只能拆分原文，不能改写或插入文案。原稿与供应商字词必须逐字对应，允许忽略空白与标点，数字读音替换或漏词会显式报错。人工听检与 0.5 秒精度验收仍不可省略。

### 5. TTS 2.0 WebSocket 协议说明
`seed-tts-2.0` / `seed-icl-2.0` 自动使用 WebSocket V3 双向流式接口，启用 `enable_subtitle`，收集 `TTSSubtitle`(364) 的 `words[].word/startTime/endTime` 秒值和音频，等待 SessionFinished 后结束连接。目前支持中英文，不启用 SSML / LaTeX。

### 6. 1.0 HTTP 协议兼容
1.0 资源保留 HTTP 单向流式协议（JSON 行 `code=0` 为数据、`code=20000000` 为成功结束标记，base64 `data` 和 `sentence.words`）。此前 HTTP 2.0 返回空词表，不代表原生 WebSocket 字幕不受支持。时间戳缺失、句内重置、原文不匹配或字段不兼容时会失败，不猜测时间基、不按字数估时，也不自动增加 ASR 调用。

### 7. 字幕折行、预算与超时控制
- 过长供应商短语的字幕会分成两行、每行最多 22 码点，细分时间属于插值，不冒充真实词级时间戳。
- 900s 预算在工作流检查点验证；独立 Worker 的硬中止与任务恢复属于第三阶段，目前外部 I/O 使用超时而非进程级硬截止。初期生成失败不自动重试付费请求，也不自动恢复；原始音频保留供排错。
- `npm run test:workflow` 使用 MockTransport / 模拟 WebSocket 验证请求、二进制协议、会话结束、晚到字幕、错误与超时，并验证真实 FFmpeg 转码；测试时间戳是替身，**不调用付费接口，也不代表真实语音对齐验收通过**。

## 使用自己的最终 DSL

### 音频放置与 DSL 映射
把音频放在 `apps/renderer/public/` 内，例如 `audio/scene_1.wav`；DSL 的 storage_key 对应 `audio/scene_1.wav`，不是绝对路径或 URL。复制示例结构修改，并更新真实音频的 checksum 与 duration_ms。

### 校验与渲染命令

```bash
python3 packages/video-schema/validate.py examples/demo.json
npm run render -- path/to/project.json output/custom.mp4
```

### 校验范围与规则
Python CLI 只检查 DSL，不检查磁盘上的音频；导出 CLI 还会核验真实资产。非法 JSON、未知字段、未来 Schema、无效引用、循环流程、cue 越界、字幕重叠、超长内容均拒绝。

### 时间轴帧号与 cue 码点计数
- 时间轴使用场景局部帧号；字幕区间为 `[start_frame,end_frame)`，全片偏移由导出器计算。
- 前后各留 6 帧；场景时长必须为 `ceil(duration_ms × 30 / 1000) + 12`。
- cue 区间按 Unicode 码点计数，不是 JavaScript UTF-16 下标。

### Studio 预览与网络安全
- Studio 直接预览输入 props，不代替完整导出前的资产核验。仅在可信本机使用，不暴露公网。
- 为限制网络绑定，`scripts/loopback.cjs` 使用了固定版本 Remotion 的内部配置 API；升级依赖时必须重新跑回环配置测试和实际监听检查。

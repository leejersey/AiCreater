# 交互改进（2026-11-26，第二轮）

承接 `2026-11-26-studio-ux-fixes.md`。不调用付费模型；价格只用已核对的配音价和 `.env` 里配置的 DeepSeek 价格，不在代码里写模型价格。

## 1. 本机草稿自动恢复（新建页）
`useLocalDraft(..., {autoRestore:true})`：同版本的本机草稿直接恢复，表单不锁；顶部一行「已恢复 X 暂存的草稿 · 丢弃并重新开始」，丢弃后可「撤销」。项目音色等其它表单保持原来的显式恢复。

## 2. 按阶段显示工具（新建页）
- 没有文稿：构思、长文转脚本、去选题台。
- 有文稿：工具条分两组——「改写」（开场钩子、去 AI 味）与「检查」（内容审核、文稿体检）；长文转脚本收进「更多」。
- 发布套件从新建页移除（工作台保留）。

## 3. 审核标在文稿里
- 分镜卡片每段列出本段断言（有来源 / 二手 / 找不到来源，悬停看证据），文稿改过后标注「可能过期」。
- 有证据包时，卡片里可点 E1、E2… 插入或去掉「依据：[E…]」；编辑区上方可展开证据包。
- 审核报告里点段落名跳到对应卡片。

## 4. 全局任务中心
- `GET /api/tasks`：本账号排队 / 运行中的配音、对齐、Agent、导出、换主题任务与拆解，以及 15 分钟内结束的任务。
- 顶栏任务托盘：有任务时显示数量与进度，点开列表可跳转；任务结束弹出提示（可点击查看）。

## 5. 花费
- 内容类模型调用（选题、拆解、文稿、钩子、去 AI 味…）记录 token 用量（`llm_usage` 表，区分服务端模型 / 你的模型）。
- `GET /api/usage`：今日 / 本月的配音金额、内容模型与 Agent token（配置了 DeepSeek 价格时折算元）；按类型给出最近 10 次的平均花费。
- 个人中心显示用量；选题台的付费确认弹窗显示「按最近 N 次平均约 ¥X / 约 N token」。

## 6. 课程进度条
- 工作台顶部：文稿 → 内容审核 → 配音 → 画面 → 导出，每步显示状态，点击跳到对应位置。
- 作品库卡片显示同样的小进度条与「下一步」。

## 7. 公式与大纲对应
大纲每章标出对应的公式步骤（章数相同时一一对应，否则按时间位置）；章数或总时长与公式偏差大时提示。

## 8. 可逆操作用撤销代替确认
删除拆解 / 公式、清除带入的资料 / 公式：先隐藏，提示里可「撤销」，6 秒后才真正删除（离开页面时立即执行）。付费操作仍先确认。

## 9. 首次使用引导
- 选题台关键词为空时给出常见领域，点一下加入。
- 作品库为空时：三步说明，并可「用示例文稿创建一门课（免费）」。

## 10. 选题卡筛选与对比
按平台、时效、只看收藏、最低总分筛选；勾选 2–3 张并排对比。

## 11. 整课自动生成
显示预计剩余时间（按已完成章节的平均耗时）；全部跑完、有待确认章节时自动进入连续审片（只自动打开一次）。

## 验证
Python（任务、用量、列表的导出状态）、TS（草稿自动恢复、公式对应、进度条、筛选、剩余时间）、浏览器检查全部流程，均不发出付费请求。

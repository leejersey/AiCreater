# 交互优化开发清单（2026-11-08）

目标：做一门课少点、少想；每一步都知道下一步是什么。全部免费开发与测试；涉及付费的流程（整课流水线）只用模拟 worker 与数据库测试，真实付费运行另需用户「开始」。

| # | 项 | 做法 | 状态 |
|---|---|---|---|
| 1 | 每章一个主按钮 | 按章节状态算出唯一的下一步（配音 / 对齐 / 生成视频 / 确认此版本 / 下一章），放在章节顶部；其余操作收进「更多操作」 | 待做 |
| 4 | 新建后自动整理章节 | 创建课程时直接按口播拆好章节（免费），进入工作台即可配音 | 待做 |
| 2 | 整课流水线 | 一次确认总预算（配音费用 + 每章 Agent 轮数上限），执行器自动串起「配音 → Agent」，只在逐章确认处停；失败的章节停下不重试；模型配置变更则整条流水线停止 | 待做 |
| 3 | 连续审片模式 | 待确认章节连续播放；每章「确认 / 写意见 / 跳过」；快捷键 J/K 切章、Enter 确认 | 待做 |
| 5 | 按时间点提意见 | 视频暂停时「在 mm:ss 处提意见」，自动带上该时刻的口播句子，Agent 据此定位 | 待做 |
| 6 | 生成过程看画面 | Agent 运行时显示最新一轮渲染的关键帧缩略图 | 待做 |
| 7 | 费用换算 | 确认弹窗与页头显示费用：配音按已核对的火山价格换算成元；DeepSeek 价格由 `.env` 配置（`DEEPSEEK_PRICE_*`），未配置时显示 token 数，不编造价格 | 待做 |
| 8 | 侧栏只放章节 | 主题、音色移到页头「课程设置」面板 | 待做 |
| 9 | 课程列表缩略图 | 最近一个通过检查的视频关键帧；没有时用主题色卡 | 待做 |
| 10 | 失败提示可操作 | 失败原因附操作：去个人中心检查模型、重新提交、刷新 | 待做 |
| 11 | 删除章节可撤销 | 删除后 10 秒内可撤销（软删除恢复） | 待做 |
| 12 | 状态推送 | 服务端事件流（SSE），有变化即刷新；保留低频轮询兜底 | 待做 |

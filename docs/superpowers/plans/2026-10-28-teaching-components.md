# T4 可复用教学组件

沿用已批准的 T4 设计，不改变 Remotion 或工作台入口。组件只接收组件引用、状态、文案和稳定 ID；尺寸、轮廓、端口、文字区、遮挡、审计区域由宿主定义。不是新一轮自由源码生成。

## 本轮任务

- [x] 为 document、wallet、classifier、loop-node、container、indicator 定义共享版本的本地几何和真实图形。
- [x] 为关系派生的 connector 定义确定性折线路径及端点，不允许模型提交路径。
- [x] 用同一份几何定义生成前景、背景、文字和接收槽裁切；未知状态、放不下的文字、非有限路径明确拒绝。
- [x] 离线测试状态、文字保留、端口、碰撞区域、身份、遮挡次序和确定性。
- [x] 输出本地组件图谱并检查实际栅格画面，保留验证记录。

不实施 T5 整章编排、T6 修订、T7 预算或 T8 生产接入。不调用模型/TTS。图谱是开发验证，不是教学视频、容器渲染验收或盲测结果。组件采用固定本地尺寸，整章摆放、交接与时间由 T5 负责；布局无解必须拒绝。

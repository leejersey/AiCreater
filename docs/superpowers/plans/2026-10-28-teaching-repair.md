# T6 自动修复实施

沿用已批准的T6，不请求模型、不执行新场景、不修改已有样片数据。分阶段交付，T6整体在真实修订闭环完成前保持进行中。

- [x] A 免费辅助对象编排修复：共享布局器对辅助对象尝试固定槽位及有界格点，保留原生尺寸、全部文案/对象和12px间隔；无解明确拒绝。复用已有文字换行和全尺寸避障路线求解，不引入模型坐标。
- [x] B 有效计划的离线诊断/修订契约：有效计划编译失败时区分内容限制与不支持能力；生成绑定原计划/口播的结构化诊断，修订不得删除对象、文字或逐节拍动作，不自动派发请求。意外基础设施错误不得伪装成内容失败。
- [x] C1 DOM诊断与免费恢复离线基础：核对可信报告绑定、重算真实帧覆盖并分类；固定宿主槽位变体，至多原版加两轮完整复检，保留原始失败；显式恢复渲染入口，不切默认。
- [ ] C2 真实浏览器恢复验收、其他主机构布局变体及预算/任务闭环：依赖T7根任务额度及T8入口，最多一次模型计划修订，重新完整检查；付费测试另定预算。

C2已部分验证：正常场景实际渲染、真实长标题失败阻断及共享标题自动排版均通过；尚无实际几何故障触发后切换变体成功的浏览器案例，C2不勾选完成。

本轮完成A/B的离线基础和自动测试。它不能宣称任何模型已成功修复，也不把数值编译通过当成MP4或视觉验收。旧冻结产物不静默迁移。

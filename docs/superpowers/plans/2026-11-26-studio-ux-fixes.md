# 选题台与新建流程：设计与交互修复（2026-11-26）

来源：对选题台、拆解库、新建视频、课程工作台的走查（代码 + 1440 / 390 宽截图）。全部为本地免费改动，不调用付费模型。

## 一、流程断点

1. **带入新建页会串题**（`courses/new/page.tsx`）。新建页已有内容（选题 / 补充想法 / 文稿 / 构思 / 证据 / 公式任一非空）时，带入前弹窗三选一：
   「换成新草稿」（清空选题相关字段，保留受众、时长、风格、格式、主题）/「只补充证据和公式」/「取消」。空草稿直接带入。
   公式带入不再写「补充想法」（公式已按结构传给大纲与文稿，`formulaToNotes` 删除）。
2. **审核门槛不提前提示**。
   - `request()` 对 409 `review_required` 保留服务端原文（不再被改写成「版本冲突」），`visualError` 原样显示。
   - `nextStep` 增加 `review` 步：审核未通过时，「配音 / 生成视频」这一步改为「先通过内容审核」，按钮打开审核弹窗。
   - 任何操作收到 `review_required` 时自动打开审核弹窗。
3. 审核报告里「在『热点与爆款参考』里注入资料」改为指向选题台；课程内显示「修改口播或逐条确认」。

## 二、信息架构

4. 选题台只保留「今日选题」「拆解库」两个标签；去掉占位的「文案」和重复的「审核」（新建页与课程里的审核保留，`/api/studio/review` 保留）。
   顶部流程提示改为「下一步：新建视频 →」。当前标签写进网址（`?tab=breakdowns`），刷新 / 后退不丢。
5. 「检索热点 / 文字拆解 / 三平台方案」移到「今日选题」。
6. 首页：登录后导航加「选题台」，主按钮旁加「去选题台找选题」。
7. 新建页工具按钮加说明（内容审核 = 事实溯源 + 合规，和配音前门槛同一套规则；文稿体检 = 结构与节奏打分，本机计算）。
8. 新建页「已注入爆款参考」改为「已带入资料 · N 条事实（文稿按它写，审核按它溯源）」。

## 三、交互 bug

9. 收藏 / 切换日期只重读选题，不再用服务器值覆盖正在编辑的关键词。
10. 公式一旦修改即回到「待确认」，「带到文案」要求重新确认；有未确认修改时切换公式先确认。
11. 拆解库：失败的可「重试」，任何非运行中的拆解可「删除」（同时删除本机视频与关键帧）；公式可删除。失败原因改为人话（模型返回不合格 / 服务繁忙 / 密钥被拒）。
    新接口：`POST /api/studio/breakdowns/{id}/retry`、`POST /api/studio/breakdowns/{id}/delete`、`POST /api/studio/formulas/{id}/delete`。
12. 上传显示进度百分比（XMLHttpRequest 上传进度）。
13. 列表上方提示「勾选 1–5 张已完成的拆解卡提炼公式」，第 6 张给出提示。
14. 拆解卡：没有时间的节奏点不再显示「?s」；「资料里看不出」的项合并成一行说明。
15. 显示的不是今天的选题时，明确提示「这是 X 的选题，今天还没有生成」（接口返回 `today`）。
16. 公式秒数输入夹在 3–60，清空不写 0。

## 四、视觉

17. 手机宽度：关键词表单改为单列。
18. 拆解库添加区：上传改为按钮样式（隐藏原生文件框），三栏按钮对齐到底部；刷新按钮移到列表标题行。

## 验证

- Python：`test_breakdowns`（重试 / 删除 / 友好报错）、`test_topics`（`today`）。
- TS：`next-step`（审核步）、`studio`（去掉 `formulaToNotes`）、`editor`（409 原文）。
- 浏览器：重写 `/tmp/pw-runner` 下的检查脚本，覆盖带入弹窗、标签网址、收藏不丢关键词、公式重新确认、重试 / 删除、手机宽度截图。

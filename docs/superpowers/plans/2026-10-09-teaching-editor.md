# 本地教学编辑器

沿用批准的Next.js/FastAPI路线。首版三栏：项目/场景列表、真实Remotion Player预览、口播/代码/步骤JSON编辑。可创建文稿、生成分镜、上下重排、确认候选、单场景配音、冻结版本导出与下载；持久任务列表支持重开后继续查询/取消/显式重试。

复用Video组件，给预览传服务端校验的音频URL；Node导出默认staticFile保持不变。后端补项目列表、任务列表和受项目约束的音频读取，禁止用户文件路径。未保存编辑不得被轮询重置，409保留草稿并提示冲突。界面提示技术内容需校对、付费动作需确认，代码不执行。

不做自由拖拽、多租户、富文本代码IDE、主题研究生成。先补小测试，类型检查/生产构建及本地浏览器验证；不触发真实付费生成。

实施完成：Next.js16.4.0 + Player4.0.534；项目/任务列表与校验音频接口已接入，复用Video且保留Node导出staticFile默认路径。步骤以JSON编辑，但编号、顺序、cue和流程边沿用后端只读约束，结构调整走候选；不提交不支持的edges字段。未保存输入由同步ref保护，冲突保留草稿，浏览器离开有确认。

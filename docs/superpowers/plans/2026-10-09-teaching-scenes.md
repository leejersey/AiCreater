# 编程 / AI 教学场景

用户重申：生成视频必须服务编程语言和 AI 教学；批准优先补教学能力，不先做后台。

## 最小设计

- 保留现有 DSL 1.0 和三类模板；新增 `code_walkthrough`。旧项目继续有效。
- 代码场景持有 `code={language,source}`；代码是纯展示文本，最多 16 行，每行最多 48 显示单位（非 ASCII 计 2），禁止不可见控制字符，不折行破坏缩进。
- 元素作为教学步骤，持有 `code_lines`（1-based 行号）、`variables`（最多 3 个 name/value）、`output`。步骤 cue 必须按原稿顺序，最终入场时间严格递增；当前步骤在下一步前保持。
- 左侧代码行号与行高亮，右侧解释、变量快照及结果；不自动执行 LLM 生成代码，不把展示的状态冒充执行器真实输出。
- AI 教学先复用现有流程图：输入 → 检索/处理 → 模型 → 输出。DeepSeek 提示词以教学为目的，不将营销标题和抽象卡片当代码教学；不会自动改写用户口播。
- 验收示例：Python 累加（初始化、两次循环、打印）与 RAG（查询、检索、上下文、模型、含来源的答案）。代码例子由开发者编写，在测试中验证已知源码的实际输出；其他 LLM 内容仍需审核。

## 实施顺序

1. 先添加 TS/Python 同构 DSL 拒绝测试和寻帧状态测试，确认失败。
2. 同步 Schema、生成类型、中间 Schema、双语言语义校验、布局与代码渲染；更新提示词及正文契约。
3. 添加两个完整教学分镜样例，复用生成工作流配音；增加接受已校验分镜的 CLI，不重复调用 LLM，也不接受资产或帧号。
4. 校验样例真实输出 / DSL / 预览帧，运行所有自动测试和类型检查；导出教学示例 MP4/SRT，记录未完成验收。

不增加沙箱执行器、任意拖拽、3D 或语法高亮依赖；先实现行高亮。没有 Git 仓库，不创建提交或代理。

## 实施与核验

- 新增 code_walkthrough Schema、生成类型和 TS/Python 同构检查；保持旧三类模板兼容。代码正文/步骤说明 32px，辅助状态至少 24px；步骤说明最多 32 码点，以保留安全区，不靠缩小字号塞入代码。
- 新增 CodeLesson 纯帧组件；高亮、教学快照和输出在下一步前持续，支持循环重复行高亮。canvas 在加载中文字体后检查真实代码宽度，超宽停止渲染。
- 教学提示词实际调用 DeepSeek 通过：能生成 code_walkthrough 与变量/输出字段，但自动生成事实不保证正确，不执行其源码。
- --storyboard 提供已经审核的教学分镜入口；64KiB 限制，原稿/结构/语义校验通过后才能调用 TTS。附有配套 txt 原稿。
- Python 固定示例的输出 5 与六步变量状态已由测试核验；只执行维护的字面量测试代码，不执行用户/模型字符串。六步分别高亮 [1]、[2]、[3]、[2]、[3]、[4]。
- 真实 TTS 2.0 配音生成的产物：output/python-sum-teaching-v4.mp4 / .srt（512帧，17.067s），output/rag-teaching-v2.mp4 / .srt（879帧，29.312s）。都是1080P/30FPS、H.264/AAC；后续布局/分镜修正复用已保存音频与词表，不重复配音费用。
- RAG 的无依据分支从 retrieve 指向 boundary，不是回答后的必经节点；有测试保护。示例知识库退货规则是教学假设，不声称现实政策。
- 已生成12个教学步骤帧，并抽查若干关键帧与最终版截图；不宣称每个帧已被人工审查或 0.5s 指标通过。
- 最终核验：71项 TS + 34项 Python 测试通过，类型检查通过；两个最终 DSL 独立验证通过，两个最终 MP4 全片 FFmpeg 解码通过。
- 仍待20组教学样例、人工听检/同步精度和任意自动生成代码内容审核。后台、持久化和任务恢复尚未实现。

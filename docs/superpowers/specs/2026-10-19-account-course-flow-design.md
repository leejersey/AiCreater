# 账号与课程工作流（已获用户“推进”确认）

目标：真实注册/登录 → 我的课程 → 免费新建草稿 → 独立课程编辑 → 预览/冻结/导出。复用FastAPI、PostgreSQL、Next.js及全部现有编辑组件；不增加服务/队列/存储/部署。

## 范围与边界

- 首版用户名（3–32位ASCII字母数字下划线，大小写归一）+6–128字符密码（按用户后续反馈放宽首版12字符限制）。服务端scrypt哈希，随机会话Cookie（HttpOnly、SameSite=Strict、7天），数据库只存token摘要；退出/改密码撤销会话。小范围本机试用，Cookie仅在回环HTTP使用，不因有登录就改为公网服务。
- 注册、登录、密码修改限次，跨站写入受Origin和JSON Content-Type检查；不接短信/邮件/社交账户/团队/计费平台。找回密码通过本机维护命令，不暴露公共重置接口。
- 浏览器同源`/api`由现有Next rewrites转发至原API。FastAPI统一认证/资源授权；课程、场景、候选、版本、job、render、asset/download均验证项目归属。未登录401，非本人资源404。页面隐藏不充当权限检查。
- 新课程原子绑定当前用户；项目列表只返回本人课程。旧课程owner为空，仅由本机明确指定用户名及项目ID认领（不能覆盖已有归属），不自动送给首位注册者。API不提供任意认领入口。
- 课程列表独立`/courses`，新建`/courses/new`，编辑`/courses/[id]`，登录/注册及密码修改单独入口。未认证先登录；401保留编辑器输入并展示原位重新登录，不自动重发任何写请求。安全校验登录返回地址。
- 原有草稿格式保留，存储前缀按userId隔离；不自动归属/展示旧匿名草稿，不删除旧备份。切账号清空页面内存，草稿明确标为本机明文而非云端保存。
- 新建先只保存文稿，随后主动AI生成（费用确认）或手工场景。编辑复用现有保存/revision/dirty保护，独立地址记录所选场景，刷新/前进后退恢复；导航处理未保存修改。

## 分期交付

1. 真实账号、会话、授权、旧数据认领和回归测试，未验收不切换运行环境。
2. 登录/注册/账号页、同源请求和本机草稿隔离。
3. 我的课程和免费新建页。
4. 独立编辑页和导航/会话失效/保存反馈。
5. 隔离数据库、浏览器与全套回归；文档、交付证据。原环境变更先备份并明确账号归属，不擅自认领原数据。

## 验收

- 两个独立会话：列表隔离，猜项目/scene/version/job/candidate/media/download ID均不可越权；未认证不访问课程。
- 注册大小写重复、无效输入、登录错误/限次、token篡改/过期/退出、改密码撤销旧会话、跨站写入均测试。
- 旧数据不被首个账号继承；维护认领只影响显式列出的无主课程。
- 新建草稿不创建job、不调用供应商；编辑旧组件行为、冲突/草稿恢复保留。
- 登录后原路径恢复；会话失效不清空输入、不重发收费请求；共享浏览器账号不串草稿。

本项目无首次Git提交，不能创建有效工作树或只提交本轮变更；不为满足流程将全部未跟踪项目首次打包提交。仅当前会话直接实现/自审，不因复杂度自行委派。
